# 📘 Markdown Parser

## 1. Khái niệm

Markdown là ngôn ngữ đánh dấu nhẹ, giúp trình bày văn bản bằng các ký tự đơn giản. File Markdown thường có đuôi `.md`.

**Markdown Parser** là công cụ đọc cú pháp Markdown và chuyển đổi nó thành nội dung được định dạng để hiển thị.

## 2. Các cú pháp Markdown cơ bản

### 2.1. Heading (Tiêu đề)

Sử dụng dấu `#` để tạo tiêu đề. Số lượng dấu `#` quyết định cấp độ tiêu đề.

```markdown
# Tiêu đề cấp 1
## Tiêu đề cấp 2
### Tiêu đề cấp 3
```

### 2.2. Bold và Italic

- **Bold:** Làm chữ in đậm bằng `**`.
- *Italic:* Làm chữ in nghiêng bằng `*`.

Ví dụ:

```markdown
**Đây là chữ in đậm**

*Đây là chữ in nghiêng*
```

### 2.3. Code Block (Khối mã)

Sử dụng ba dấu huyền ngược để tạo khối mã. Có thể ghi tên ngôn ngữ sau ba dấu để làm nổi bật cú pháp.

Ví dụ:

````markdown
```python
print("Hello World")
```
````

Kết quả là một khối mã Python:

```python
print("Hello World")
```

### 2.4. Blockquote (Trích dẫn)

Sử dụng dấu `>` để tạo phần trích dẫn hoặc ghi chú.

Ví dụ:

```markdown
> Ghi chú: Cần kiểm tra cú pháp Markdown trước khi lưu tài liệu.
```


### 2.5. Link (Liên kết)

Sử dụng cú pháp `[Tên hiển thị](đường_dẫn)` để tạo liên kết.

Ví dụ:

```markdown
[Hướng dẫn Markdown](https://www.markdownguide.org/)
```

Liên kết tham khảo: [Markdown Guide](https://www.markdownguide.org/)

## 3. Lợi ích của Markdown

- Dễ học và dễ sử dụng.
- Nội dung dễ đọc ngay cả khi chưa định dạng.
- Phù hợp để viết README, ghi chú học tập và tài liệu dự án.
- Được hỗ trợ trong Visual Studio Code và GitHub.

## 4. Bài tập tự kiểm tra

- [ ] Tạo được tiêu đề bằng dấu `#`.
- [ ] Phân biệt được chữ in đậm và chữ in nghiêng.
- [ ] Tạo được khối mã bằng ba dấu huyền ngược.
- [ ] Tạo được trích dẫn bằng dấu `>`.
- [ ] Tạo được liên kết bằng cú pháp Markdown.

## 5. Tổng kết

Markdown là công cụ hữu ích giúp em ghi chép và trình bày tài liệu học tập. Em cần luyện tập các cú pháp cơ bản để tạo ra những file `.md` rõ ràng, dễ đọc và dễ quản lý.
